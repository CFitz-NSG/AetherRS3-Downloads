# AetherRS3 Downloads

Official launcher and client downloads for AetherRS3.

## Download status

The launcher is being prepared and tested. There is no playable public release available yet.

When ready, download the complete launcher package from [Releases](https://github.com/CFitz-NSG/AetherRS3-Downloads/releases), extract it, and open AetherRS3.bat. The launcher will check for client updates before starting the game. Enter your game credentials only inside the game client.

This repository contains public distribution material only. Server source, account data, player saves, and private configuration are maintained separately.
